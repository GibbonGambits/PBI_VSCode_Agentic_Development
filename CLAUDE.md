@.github/copilot-instructions.md

The file above holds the rules for every task in this repository. It was written for GitHub Copilot; follow it the same way.

The skills it names are in `.github/skills/<name>/SKILL.md`. Before the work a skill covers, read its SKILL.md and the reference files it points to. Do the same for the file-type rules in `.github/instructions/` before you edit a file they cover.
